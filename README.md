# Seto Yoki Portfolio

A responsive Next.js + TypeScript portfolio inspired closely by the supplied reference site.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Customize

Edit `app/page.tsx`:
- name and hero copy
- skills
- project list
- email/social links
- about section

The visual system, responsive layout and Framer Motion animations are already wired up.

## Build

```bash
npm run build
npm start
```
